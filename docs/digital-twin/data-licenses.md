# 바닥·건물 데이터 라이선스 확인표 (P0 보완)

> 이 표는 **법률 검토가 아니다.** 아래 "확인된 것"은 일반적으로 알려진 조건이며, 서비스에 올리기 전에 각 출처의 최신 약관을 직접 확인해야 한다. 이 세션에서는 약관 원문에 접속하지 못했다.

| 출처 | 쓰는 곳 | 알려진 조건(확인 필요) | 상태 |
|---|---|---|---|
| OpenStreetMap (Overpass) | 도로·보도·횡단보도·건물 외곽 타일 | ODbL: 출처 표기("© OpenStreetMap contributors") 의무. **가공한 데이터베이스(우리 타일 JSON)를 공개 배포하면 동일 조건(share-alike)으로 공개해야 할 수 있다**: 화면 렌더링 이미지(Produced Work)와 타일 파일(파생 DB)을 구분해 검토 필요 | 표기는 화면 범례에 구현. share-alike 해석은 **미결정(소유자/법무 판단)** |
| Overpass 공용 서버 | 내려받기 | 공정 사용 정책, 대량 요청 제한. 서비스 운영용 대량 사용은 자체 인스턴스나 Geofabrik 추출본 권장 | `--sleep`, 조각 캐시로 완화. 운영 전략 미정 |
| 네이버 지도 | 2D 지도 UI(기존) | 지도 타일/화면을 3D 텍스처로 쓰거나 도로 도형을 추출하는 것은 **허용 여부 미확인**. 사용하지 않음 | 미사용 |
| 서울시 S-Map 오픈랩 / 열린데이터광장 | (후보) 도로면·건물 보강 | 데이터셋별 이용허락(공공누리 유형 등) 상이 | 미사용, 후보 |
| 브이월드(국토부) | (후보) 연속지적도·건물 | API 키·이용약관·표기 의무 확인 필요 | 미사용, 후보 |
| 구 경계(`seoulBoundaries.ts`) | 구 경계선 | southkorea/seoul-maps (MIT, 통계청 2013 기반) | 기존 저장소 데이터 |

## 결정이 필요한 것
1. 공개 배포되는 정적 타일(`public/data/ground/`)이 ODbL의 파생 데이터베이스에 해당하는지, 해당한다면 타일을 ODbL로 공개할 것인지(또는 서버에서만 제공하고 화면 이미지 형태로만 노출할지).
2. 운영용 데이터 공급 방식(공용 Overpass 직접 호출 금지 → 정기 배치로 생성한 타일만 배포).
3. 공공 데이터(S-Map/브이월드)로 대체·보강할지.

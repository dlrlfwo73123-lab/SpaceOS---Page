# P4 – 실제 건물 외곽 입체와 층 줄무늬 (도면 5 방식)

> "P4"는 앞서 정리한 계획(P0~P3)에 없던 단계라, 미뤄 둔 항목 중 효과가 큰 것으로 정했다: 가짜 주변 건물을 OSM 건물 외곽 기반 입체로 교체 + P0에서 빠진 라이선스 확인표.

## 구현
| 영역 | 내용 |
|---|---|
| 데이터 | `tools/ground/osm_buildings.py`: 닫힌 `way[building]` → 외곽(0.3m 단순화, 5㎡ 미만·60점 초과 제외). Overpass 쿼리에 `way["building"]` 추가 |
| 높이 규칙 | `height` 태그(m) > `building:levels`×3.5m > 기본 7.0m. **태그가 아닌 값은 모두 `e=1`(높이 추정)** 으로 타일에 기록 |
| 타일 | 타일 JSON에 `buildings: [{r:[lon,lat,…], h, l, e}]` 추가(중심점 기준 타일 배정). 건물만 있는 타일도 생성 |
| 프런트 | `lib/extrude.ts`(귀 자르기 삼각분할·벽/지붕·층 UV·앞면 와인딩), `components/BuildingLayer.tsx`. 벽에 층 줄무늬 텍스처(1층 = 3.5m), 높이 추정 건물은 한 단계 연한 색 |
| 선택 건물 | 선택 건물(18×13m)과 겹치는 OSM 건물은 숨김. 층 슬래브 색(P2)은 그대로 |
| 성능 장치 | ① 200m 격자 조각 메시로 나눠 화면 밖은 컬링 ② 단면(FrontSide) 렌더링 ③ 그림자는 300m 안 조각만 ④ **PerfGovernor**: 2.5초 평균 fps < 24면 건물 표시 반경을 600 → 400 → 250 → 120m로 한 단계씩 축소하고 범례에 "성능 보호" 표시(되돌리지 않음). 개발용 `?nogov`로 끌 수 있음 |
| 검증 스크립트 | `node apps/frontend/scripts/check-extrude.mjs` (삼각분할 면적 보존, 법선 바깥, 앞면 방향, 층 UV, 중심 겹침 판정) |

## 측정 (합성 고밀도 도심 3,000동/km² — 실데이터 아님, 소프트웨어 렌더러)
| 항목 | 값 |
|---|---|
| 건물 17,280동 처리 시간 | 4.0 s (서울 70만 동 외삽 약 2.7분, 실데이터는 더 걸릴 수 있음) |
| 1회 열기 전송량(9타일, gzip) | 0.66 MB (예산 1.5 MB) |
| 렌더 삼각형(바닥 + 600m 건물) | 약 5.8만 (예산 25만) |
| 프레임: 기준(건물 없음) | 11.2 fps |
| 프레임: 건물 600m, 보호 장치 끔 | 3.5 fps (**−69%, −20% 기준 미달**) |
| 프레임: 보호 장치 켬(자동으로 120m) | 8.7 fps (−22%) |
| 개선 이력 | 양면 렌더+단일 메시+전체 그림자 2.0 fps → 단면+조각 컬링+근거리 그림자 3.5 fps |

해석: 소프트웨어 렌더러는 픽셀 채움 비용이 지배적이라 실제 GPU와 다르다. 그러나 600m 전체 표시는 이 측정에서 기준을 넘지 못하므로 **기본값 600m는 실기기 측정 전까지 잠정**이다. 실기기에서 30fps 미만이면 `BUILDING_RADII` 첫 값을 낮춘다.

## 정정
측정 중 한 번 "Lambert 재질 60fps"라는 값이 나왔으나 임시 수정의 JSX 닫는 태그 오류로 **컴파일 오류 화면을 측정한 무효 값**이었다. 다시 측정한 Lambert 결과는 2.5 fps로 재질 변경 효과가 없어 표준 재질을 유지했다.

## 한계
- 실데이터로는 아직 생성하지 못했다. 건물 수·태그 비율(높이 추정 비율)은 실제 OSM에서 달라진다. 서울은 `building:levels`가 없는 건물이 많아 **추정 비율이 높을 가능성**이 크다(합성 샘플은 64%).
- multipolygon(relation) 건물, 구멍(중정) 있는 외곽, 지하·경사 지붕은 처리하지 않는다.
- 건물 높이/층수의 출처가 OSM뿐이라 선택 건물의 공실 층 정보와 연결되지 않는다(P2의 `certainty`는 여전히 placeholder).
- 건물 외곽 데이터의 라이선스 판단은 `data-licenses.md`의 미결정 항목에 해당한다.

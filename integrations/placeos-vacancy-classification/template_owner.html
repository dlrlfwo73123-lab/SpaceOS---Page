창업 가능 공실 개 중 건물주가 직접 올린 공실

앞 보고서 「공실 창업 가능성 분류」에서 창업 여력 있음 개 · 창업 가능 · 여력 얇음 개로 나온 빈 층을, 건물주가 PlaceOS 직거래로 직접 올린 공실(소유자 확인 · 게시 중)과 PlaceOS가 자료로 찾은 빈 층으로 나눴습니다.

  • 창업 가능 분류: 확인 빈 층 개 중 개 ( 분류)
  • 건물주 매물: PlaceOS 공개 API /api/v1/direct/listings · ·
  • 행위제한 토지이음

이 보고서는 매물을 고르거나 추천하지 않습니다. 건물주 매물은 공개된 조건을 그대로 옮기고, PlaceOS 직거래 원칙(성사 수수료 없음 · 조건을 대신 조율하지 않음)을 따릅니다. 앞 보고서: 공실 창업 가능성 분류(같은 폴더).

지금 상태두 공실의 차이가르는 규칙상권별건물주 매물층별 목록한계 · 재현

지금 상태

건물주 매물은 보고서를 만든 시각에 PlaceOS 공개 API 에서 읽었습니다. 읽지 못하면 0 으로 세지 않고 「모름」으로 둡니다.

두 공실은 무엇이 다른가

같은 「빈 층」이라도 누가 올렸는지에 따라 아는 것이 다릅니다.

누가 올리나건물주 본인(또는 위임받은 대리인 · 관리단)PlaceOS 가 공공 자료를 대조해 자동으로

단위층 · 호실층 전체(어느 호실이 비었는지는 모름)
임대 조건보증금 · 월세 · 관리비 · 렌트프리 · 입주 가능일을 건물주가 적음없음 — 수지의 임대료는 R-ONE 1층 임대료 × 층 계수 추정(실제 호가 아님)

등급(법·용도 · 수지)같은 건물 ID + 층이면 이번 분류를 그대로 붙이고, 수지는 건물주가 적은 월세로 다시 봐야 함이번 분류 그대로(대장 · 행위제한 · 3-Tier 추정)
공개 범위게시 중 + 소유자 확인 매물만 공개 · 소유자 이름 · 등기 정보는 비공개PlaceOS Gold 산출물

어떻게 가르나

건물주 매물의 건물 ID + 층을 빈 층 목록과 맞춥니다. PlaceOS 앱이 3D 트윈 · 자리 상세에서 「이 건물에 건물주가 직접 올린 매물이 있어요」를 붙이는 키와 같습니다.

상권별

창업 가능 층이 있거나 건물주 매물이 있는 상권입니다. 열 제목을 누르면 정렬합니다. 「건물주 매물(상권 전체)」은 이번 분류 밖 매물까지 센 값입니다.

건물주가 올린 매물

공개 API 가 돌려준 매물 전부입니다(게시 중 + 소유자 확인). 창업 가능 층과 겹치는지, 아니면 왜 분류 밖인지 매물마다 적습니다.

창업 가능 층 목록

출처(건물주 직접 등록 / 자료로 찾은 빈 층)와 등급으로 거르고 건물 이름으로 찾습니다. 줄을 누르면 건물주 등록 여부, 등급 이유, 지도 링크가 열립니다.

    한계 · 재현

    이렇게 읽지 마세요

    1. 공개 API 는 게시 중 + 소유자 확인 매물만 돌려줍니다. 초안 · 확인 대기 · 반려 매물은 세지 않습니다 — 소유자 확인 전 매물을 공개하지 않는 것이 PlaceOS 직거래 규칙입니다.
    2. 소유자 이름 · 등기 번호 · 연락처는 이 보고서에 없습니다. 공개 API 에도 오지 않습니다.
    3. 매칭은 건물 ID + 층입니다. 건물 ID 없이 주소만 있는 매물과 지하층 매물은 「분류 밖」으로 둡니다. 한 층에 호실 매물이 여럿이면 그 층에 모두 붙습니다.
    4. 등급은 앞 보고서의 추정 임대료 기준 그대로입니다. 건물주 매물이 붙은 층은 건물주가 적은 월세로 수지를 다시 봐야 하고, 이 보고서는 그 재계산을 하지 않습니다(PlaceOS Posting 「이 조건이면 얼마나 팔아야 하나」에서 합니다).
    5. 매물을 고르거나 순위를 매기지 않습니다. 건물주 매물과 자료로 찾은 빈 층을 나눠 보여 줄 뿐입니다.
    6. 숫자는 만든 시각 기준입니다. 건물주 매물은 조회 시각, 분류는 Gold 2026-10-11 빌드 기준이라 다시 만들면 바뀔 수 있습니다.
    7. 허가 판정이 아닙니다. 등급의 법·용도 판단은 건축물대장 · 토지이음 기재 기준입니다(앞 보고서와 같음).

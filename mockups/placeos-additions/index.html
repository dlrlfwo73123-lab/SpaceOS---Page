추가사항 5가지를 적용한 화면 시안

placeos.co.kr에 아래 기능이 들어갔다고 가정하고, 케이스마다 HTML 화면을 따로 만들었습니다. 각 화면 위쪽의 A · B · C 시나리오를 바꾸면 같은 기능이 다른 조건(2층 · 1층 · 지하, 운영 중 · 오픈 준비 등)에서 어떻게 보이는지 확인할 수 있습니다.

시안 기준
  • 동네: 서울 성동구 성수동 (Case 1은 마포구 망원동도 선택 가능)
  • 수치 · 점포 · 행사 일정은 모두 데모 데이터
  • 지도: 실서비스는 네이버 지도, 시안은 키 없이 쓰는 OpenFreeMap (안 되면 Esri)
  • 케이스끼리 버튼으로 이어져 실제 사용 흐름대로 이동
